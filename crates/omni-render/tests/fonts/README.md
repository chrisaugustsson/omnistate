# Test fonts

`Inter-Variable-latin.woff2` is Inter as web code self-hosts it: Google Fonts'
Inter v20, Latin subset, one variable WOFF2 file whose `wght` axis runs from
100 to 900. Inter is under the SIL Open Font License, the same as the bundled
`../../fonts/Inter-Regular.ttf` (see `../../fonts/LICENSE.txt`).
